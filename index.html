毎日くじ引きをしたら？

くじが"当たる" = くじが"当たらない" の逆？

❌ 掛け算じゃない

0.011% × 365日 = 4.0%

✅ 複利計算

1 - (99.989%)^365 = 3.9%
Step1: 連続して"当たらない"日は、何回連続？
Step2: 毎日99.989%の確率で「外れ」続ける確率を計算

指数関数と確率

P(t) = 1 - (1 - p)^t
ここで：p = 日次確率、t = 日数
(1-p)^tは指数関数。時間と共に急激に減少、
結果としてP(t)は急激に増加。これが「非線形」です。

ポアソン過程 = 「新鮮な気持ち」

N(t) ~ Poisson(λt)
P(N(t) = k) = (λt)^k e^(-λt) / k!
P(T > t) = e^(-λt)
λ ≈ 0.00011 [day⁻¹]
f(t) = λe^(-λt) (確率密度関数)
F(t) = 1 - e^(-λt) (累積分布関数)
ポアソン過程：毎日を「新鮮な気持ち」で感じる。
過去がなかったことになる。"状態を持たない"システムです。

確率測度と積分の幾何学

P(T ≤ t) = ∫₀ᵗ λe^(-λs) ds = 1 - e^(-λt)

測度空間：(Ω, ℱ, P)
σ-代数：ℱ = σ({[0,t] : t ≥ 0})
確率測度：P([0,t]) = ∫₀ᵗ f(s)ds
確率は時間軸上の測度として表現されます。上の3次元描写：
• X軸：時間 t
• Y軸：確率密度 f(t) = λe^(-λt)
• Z軸：累積確率 F(t)

曲面下の体積が確率測度を表現。
指数分布の優雅な減衰と、積分による累積の幾何学的美しさ。

無記憶性：P(T > s+t | T > s) = P(T > t) = e^(-λt)
これは条件付き確率の幾何学的な「平行移動不変性」です。

Exponential Functions & Probability

P(t) = 1 - (1 - p)^t
where: p = daily probability, t = number of days
(1-p)^t is an exponential function that decreases rapidly,
making P(t) increase non-linearly.

Poisson Process = "Fresh Start"

N(t) ~ Poisson(λt)
P(N(t) = k) = (λt)^k e^(-λt) / k!
P(T > t) = e^(-λt)
λ ≈ 0.00011 [day⁻¹]
f(t) = λe^(-λt) (PDF)
F(t) = 1 - e^(-λt) (CDF)
Poisson process: Every day starts with a "fresh mindset".
The past becomes irrelevant. A "stateless" system.
